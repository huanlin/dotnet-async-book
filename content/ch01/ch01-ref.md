# Chapter 1: 非同步程式設計與多執行緒

作為軟體開發人員，我們經常努力使應用程式更快、更具響應性和更高效。實現這一目標的一種方法是使計算機能夠同時執行多個任務，最大化現有 CPU 核心的使用。多執行緒和非同步程式設計是常用於此任務的兩種技術。

多執行緒允許計算機看起來像是同時執行多個任務，即使任務的數量超過 CPU 核心的數量。相對而言，非同步程式設計專注於在通常會使 CPU 等待的操作中優化 CPU 的使用，確保 CPU 保持活躍和高效。

使計算機能夠同時執行多個任務是非常有用的。它有助於保持本地應用程式在工作時的響應性，並且對於構建能夠同時與多個客戶端互動的高性能伺服器至關重要。

這兩種技術都可以用來創建響應式的客戶端應用程序或處理少量客戶端的伺服器。但當它們結合在一起時，可以大大提高性能，使伺服器能夠同時處理數千個客戶端。
